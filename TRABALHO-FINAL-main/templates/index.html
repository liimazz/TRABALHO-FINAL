O que é o MuralTech?

O MuralTech é um sistema desenvolvido para modernizar a comunicação escolar, substituindo os murais físicos por uma plataforma digital prática e organizada.

Com ele é possível divulgar eventos, provas, reuniões e comunicados importantes para toda a comunidade escolar.

O projeto foi desenvolvido utilizando Python, Flask, HTML, CSS, Bootstrap e JSON, oferecendo uma solução simples, rápida e eficiente.
